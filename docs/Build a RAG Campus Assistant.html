Build a RAG Campus Assistant

An AI chatbot that answers student questions from your college's own documents

PDFs→ Chunks→ Vectors→ Vector DB⇒ Search→ Rerank→ Prompt→ Answer

Phase 1: Preparing the Data

Done once (and repeated whenever documents change). This builds the AI's knowledge base.

1

Download & Load the Documents

What: Gather all 200 college PDFs, tuition schedules, library guides and syllabi into one folder.
How: Use document loaders to pull the raw text out of every file.
PyPDFLangChain loaders
2

Chop Files into Bite-Sized Paragraphs (Chunking)

Why: An AI can't read a 100-page document just to answer a quick question. It needs small, digestible snippets.
What: Split documents into ~300-word chunks with ~50 words of overlap so no sentence is cut in half.
Chunk 1: words 1–300  |  Chunk 2: words 250–550  |  Chunk 3: words 500–800 …
chunk_size = 300overlap = 50
3

Attach "ID Cards" (Metadata)

Why: So the AI can say "According to Page 12 of the 2026 Student Handbook…"
What: Label every chunk with details about where it came from.
source_file: "Student_Handbook_2026.pdf"
page_number: 12
department: "Housing"
4

Convert Text into Mathematical Codes (Embeddings)

Why: Computers don't understand words, they understand distance and math.
What: Pass each chunk through an embedding model. It outputs a list of numbers (a vector) capturing the meaning. Paragraphs about "tuition fees" and "class payments" land close together in vector space.
sentence-transformersvector = [0.12, -0.48, 0.91, …]
5

Store Everything in a Vector Database

What: Save the vectors and their text chunks (plus metadata) in a vector database. Your knowledge base is now ready!
Chroma DBpgvectorPinecone

Phase 2: Handling a Student's Live Question

Runs every time a student chats with the assistant (runtime).

6

The Student Asks a Question

💬 "Can I get my money back if I drop my chemistry class in Week 3?"
7

Run a Hybrid Double-Search

The question goes to two "judges" in parallel:
🔎 Word Inspector (BM25)Keyword search. Looks for exact matches like "Week 3", "chemistry", "money".
🧠 Meaning Detective (Vector)Finds similar concepts like "tuition refund", "course withdrawal deadline", "reimbursement".
8

Merge & Refine the Results (RRF + Reranker)

RRF: Reciprocal Rank Fusion combines the top results of both judges into one top-10 list.
Reranker: A specialized model re-reads those 10 paragraphs carefully against the question and picks the 3 best.
Top 10→Top 3
9

Create the Cheat-Sheet Prompt (Augmentation)

Your code builds a custom message for the LLM (e.g. Llama 3 or GPT):
You are the official Campus Assistant. Use ONLY these 3 retrieved handbook paragraphs to answer. If the answer isn't there, say "I don't know".

Context: [Paragraph 1, Page 12: Tuition Refund Schedule…]
Student Question: Can I get my money back if I drop my chemistry class in Week 3?
10

Generate the Final Grounded Answer

The LLM reads the cheat-sheet and replies with an accurate, sourced response:
🤖 "Yes! According to the Student Handbook (Page 12), if you drop a course during Week 3, you are eligible for a 50% tuition refund. After Week 4, no refunds are issued."
11

Display in the App Interface

What: Plug the Python backend into a frontend chat widget so students can use it on phone or laptop.
StreamlitReact
RAG = Retrieval-Augmented Generation: retrieve the right facts first, then let the AI answer from them.
